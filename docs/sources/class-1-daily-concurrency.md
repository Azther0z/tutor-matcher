How many calls can I host on my Daily account at the same time?

The number of concurrent calls is determined by the number of programmatic rooms on your Daily domain. With a card on file, you can have up to 100,000 simultaneous calls or sessions. [Talk to us](https://www.daily.co/company/contact) if you need more than that.
