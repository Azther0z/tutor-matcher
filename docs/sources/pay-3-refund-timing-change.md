User request: change business logic. bob can always refund after the payment is success

Question: Refund requests will open as soon as payment succeeds. What should happen before the lesson starts, and should there still be a deadline? Note: an instant 'Tutor didn't show up' refund before the lesson would give 100% back with no checks. That bypasses the 70% late-cancellation rule (BOOK-3).

Answer: No deadline, no-show after start (Recommended): Bob can file any time after payment, with no deadline. 'Tutor didn't show up' (instant refund) appears only once the lesson has started. Before that, only 'unsatisfactory/other' is offered, and it goes to an admin.

Question: Should a lesson the Tutor confirmed as COMPLETED still be refused (acceptance criterion 3)?

Answer: Keep refusing completed (Recommended): Matches AC3: the request is rejected and the reason is shown.
