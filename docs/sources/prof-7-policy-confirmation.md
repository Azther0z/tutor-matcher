Question: Can a user save more than one payout account?

Answer: Yes. A user can save several accounts and exactly one is the default. Payouts use the default unless the user picks another one.

Question: Which kinds of payout account are supported?

Answer: Thai bank accounts only: a bank from the list, the account holder name and the account number. The full number is stored but shown masked (•••• 1234) everywhere after saving.

Question: Where do the settings live, and who can open them?

Answer: At /settings/wallet, as planned in the user journeys ("Balance shortcut and payout account details"). Any logged-in user can open it, not only Tutors, because wallet withdrawals are not tutor-only.

Question: Are payout requests part of PROF-7?

Answer: No. Payout requests are PAY-7 at /wallet/payout. PROF-7 only manages the accounts, and the link to /wallet/payout is added after PAY-7.
