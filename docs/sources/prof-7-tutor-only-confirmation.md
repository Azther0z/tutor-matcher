Question: Students should not be able to withdraw money, so should they be able to add a payout account at all?

Answer: No. Close it for students: only Tutors can add payout accounts. This replaces the earlier PROF-7 answer that any logged-in user can manage payout accounts. Wallet settings stays open to everyone for the balance and Top up; the payout account list and the Add account form are shown only to Tutors, and the server rejects payout account requests from anyone else.
